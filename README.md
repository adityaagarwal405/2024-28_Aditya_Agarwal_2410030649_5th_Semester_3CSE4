## 🚀 Project: Quiz Game (Python, Console-Based)

The Quiz Game is a console application that presents multiple-choice questions with A/B/C/D options, accepts and validates the user's answer, tracks the score, calculates the final percentage, and displays a performance category based on the result.

### Core Features
- Five multiple-choice questions with A/B/C/D options
- User input reading and normalization (uppercase handling)
- Answer validation against stored correct answers
- Score tracking and percentage calculation
- Performance feedback based on final score

### 🛠️ Technologies & Tools Used

| Category | Details |
|---|---|
| Language | Python |
| Editor | Visual Studio Code (VS Code) |
| Data Structures | Lists, Dictionaries |
| Concepts | Loops, Conditional Statements (`if` / `if-elif-else`) |
| Libraries Explored | NumPy, Pandas (introductory exposure) |
| Version Control | GitHub |

### 🏗️ System Architecture

| Stage | Component | Function |
|---|---|---|
| 1 | Question Data | Stores questions, A/B/C/D options, and the correct answer |
| 2 | Quiz Loop | Displays each question and its available options |
| 3 | User Input | Reads the user's A/B/C/D response and converts it to uppercase |
| 4 | Answer Check | Compares the user's answer with the stored correct answer |
| 5 | Score Calculation | Increases the score for correct answers and calculates the percentage |
| 6 | Performance Output | Displays the final score and performance category |

### Implementation Flow
1. Prepare the question set with question text, four options, and the correct answer.
2. Iterate through each question using a loop.
3. Display the question and options to the user.
4. Read the user's A/B/C/D input and normalize it to uppercase.
5. Compare the input with the stored correct answer.
6. Increase the score when the answer is correct.
7. Calculate the final percentage after all questions are completed.
8. Use conditional logic to display a performance category and final result.
